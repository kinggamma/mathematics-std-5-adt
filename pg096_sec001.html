Example 2

Convert 7200 into decimal.

Solution

This is a simple fraction. Use long division method to divide the numerator 7 by the denominator 200 as follows:

Steps
1.

Write 7.000 to allow division with decimals

2.

Divide the first number: 7 is not sufficient to divide 200, write 0 and a decimal point in the answer

3.

Multiply 0 by 200 to get 0. Write 0 below 7

4.

Subtract: 7−0=7. Bring down the first 0 after the decimal to get 70

5.

Divide 70 by 200, it is not sufficient. Write 0 after the decimal point in the answer

6.

Multiply 0 by 200 to get 0. Write 0 below 70

7.

Subtract 70−0=70. Bring down the second 0 after the decimal to get 700

8.

Divide 700 by 200 to get 3 and write 3 in the answer

9.

Multiply 3 by 200 to get 600, subtract: 700−600=100

10.

Bring down the third 0 after the decimal to get 1000

11.

Divide 1000 by 200 to get 5 and write 5 in the answer

12.

Multiply 5 by 200 to get 1000, subtract: 1000−1000 to get 0

Solution
Long division of 7.000 by 200 gives 0.035.
