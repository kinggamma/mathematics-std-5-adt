Solving simple equations with a variable on both sides

Example 1

Find the value of x if 7x−6=x+18.

Solution
7x-6=x+18

Collect terms with variables on one side and the numbers on the other side:

7x-x=18+6

Simplify terms with variables and those without variables:

6x=24

Divide both sides of the equation by 6

6x6=246
x=4

Therefore, the value of x is 4.

Example 2

Find the value of b if 3b−4=b+8.

Solution

Collect the terms with variable on one side and numbers on the other side:

3b-b=8+4

Simplify the like terms

From 3b−b=8+4

2b=12

Divide both sides of the equation by 2:

2b2=122
b=6

Therefore, the value of b is 6.
