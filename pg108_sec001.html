Example 4

Simplify 4xy−xw+3xw+3xy

Solution

Collect like terms and simplify

4xy - xw + 3xw + 3xy = 4xy + 3xy + 3xw - xw
= (4 + 3)xy + (3 - 1)xw
= 7xy + 2xw

Therefore, 4xy−xw+3xw+3xy=7xy+2xw.

Example 5

Simplify 3a−a+4pq−pq

Solution

Collect like terms and simplify

3a - a + 4pq - pq = 3a - a + 4pq - pq
= (3 - 1)a + (4 - 1)pq
= 2a + 3pq

Therefore, 3a−a+4pq−pq=2a+3pq.
