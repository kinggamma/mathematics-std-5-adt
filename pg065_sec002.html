Activity 1
Addition of fractions with different denominators
Steps
1.

Use colored paper which is in a circular shape like a pizza, cut it into fraction of 12, 13, 14, 16 and so on.

2.

Add 12 and 13.

3.

If 12 and 13 can not be added directly, cut more pieces to make both pizzas into sixths (the least common denominator).

4.

Make the equivalent fractions

(i) show that 12=36 and 13=26

(ii) now add 36+26=56.

5. Practice more addition of fraction using fraction cards for

(i)
14+16
(ii)
23+15
(iii)
38+14

6. Why do we need to find common denominators?
