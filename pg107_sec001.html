Example 1

Simplify 6n+n+2n

Solution

First, add the coefficients: 6+1+2=9

Therefore, 6n+n+2n=9n.

Example 2

Simplify 5ae−2ab−2ae

Solution

Collect like terms and then simplify

5ae - 2ae - 2ab = (5 - 2)ae - 2ab
= 3ae - 2ab

Therefore, 5ae−2ae−2ab=3ae−2ab.

Example 3

Simplify 2a+3b−a

Solution

Collect like terms and simplify

2a + 3b - a = 2a - a + 3b
= a + 3b

Therefore, 2a+3b−a=a+3b
